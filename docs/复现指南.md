# 复现与发布说明

## 1. 直接体验

根目录运行README安装命令。仓库自带七个 `best_actor.pt`，可在CPU进行单住宅推理，无需启动语言模型服务：

```bash
python demo/app.py --checkpoint results/layout/mappo42/best_actor.pt --controller lookahead --horizon 32 --port 7861
```

打开localhost:7861，仿真自动推进。先看主表模型/规则/差值，再观察四条指标面板。输入“客厅有点冷”“省电模式”“我要睡觉了”；目标同时传给双方。切换基线会同种子重置。持续语音需要浏览器授权；服务环境未完成真实麦克风声学验收。

`--controller raw`仅用actor；`feasible`加入集中约束分配；`lookahead --horizon 32`对应最终报告架构。不传checkpoint会明确标记规则演示，不是MARL。前端不支持任意房间数，只支持四区面积和热连接编辑。

## 2. 数据与图表复核（无需训练）

```bash
python -m training.publication
python -m training.figures
python -m training.optimization_report
python -m training.report_results
```

publication检查每个汇总指标等于逐日平均，并验证最终模型hash，导出108行汇总和2160行逐日CSV。其余命令从既存JSON重画图表/更新报告区块，不会产生新的控制实验。

## 3. 重新运行控制实验

```bash
python -m training.final_study
python -m training.optimization_report
python -m training.publication
```

final_study在100020–100039、四场景、六控制器上运行480个仿真日，覆盖原actor、可行层、扩容、8h前瞻、协调规则和4h MPC。运行会覆盖同名JSON；如需保留本次发布数字，请先复制输出或使用独立工作目录。旧探索命令及参数见README、训练manifest和实验索引。

## 4. 从头训练

```bash
python -m experiments.v2.bench_train --algorithm mappo --steps 20000000 --envs 1024 --seed 42 --output results/layout/mappo42
python -m experiments.v2.bench_train --algorithm mappo --steps 20000000 --envs 1024 --seed 43 --output results/layout/mappo43
python -m experiments.v2.bench_train --algorithm mappo --steps 20000000 --envs 1024 --seed 44 --output results/layout/mappo44
python -m experiments.v2.bench_train --algorithm ippo --steps 20000000 --envs 1024 --seed 42 --output results/layout/ippo42
python -m experiments.v2.bench_train --algorithm mappo --steps 30000000 --envs 1024 --hidden 256 --seed 42 --output results/capacity/mappo256_42
python -m experiments.v2.bench_train --algorithm mappo --steps 30000000 --envs 1024 --hidden 512 --seed 42 --output results/capacity/mappo512_42
python -m experiments.v2.bench_train --algorithm mappo --steps 30000000 --envs 1024 --hidden 512 --seed 43 --output results/capacity/mappo512_43
```

本次训练使用CUDA；未验收纯CPU训练。实际步数按98304的整批取整。模型文件只包含部署actor、环境版本和训练参数；未提交巨大的完整优化器快照，不支持直接无缝续训。各运行目录附run_manifest、validation、throughput。跨库/硬件重新训练不保证逐位一致。

## 5. 验收

```bash
pytest -q
python -m training.verify_export results/layout/mappo42/best_actor.pt
python demo/app.py --checkpoint results/layout/mappo42/best_actor.pt --controller lookahead --horizon 32 --scripted
pip install -r requirements-dev.txt
python -m playwright install --with-deps chromium
# 保持第1节服务运行，然后：
python -m training.browser_check
```

导出检查比较3072个agent动作。浏览器检查固定Canvas节点、自动时钟、基线重置、连续识别结果事件、整日运行及移动端，不等于真实ASR准确率测试。结果记录在assets/evidence与assets/demo/browser_check.json。

## 6. 目录与证据边界

保留原始JSON、图表、CSV、七个推理权重和配置，排除虚拟环境、运行日志、重复快照及缓存。`docs/history`只作历史追溯，不能与当前v3结果混算提升率。旧户型视频仅作历史演示；当前界面以README截图及运行程序为准。第三方框架从依赖安装，不将其源码复制进仓库。

## 7. 导出正式报告

安装开发依赖和Chromium后运行 `python -m training.export_report`，从Markdown生成独立HTML和PDF。公式转换为SVG，图表嵌入HTML；不依赖在线数学渲染。需要系统安装中文字体才能正确打印中文。
